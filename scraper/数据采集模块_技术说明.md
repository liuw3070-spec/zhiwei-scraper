# 知微Agent · 数据采集模块技术说明

> 最后更新：2026-05-24 | 适用于 Claude Code 对接

---

## 一、模块定位

数据采集模块是知微Agent（跨境AI市场调研Agent）的**数据注入层**。它自动采集 Amazon BSR 榜单和产品评论，产出含 `weight` 和 `date` 字段的结构化 Markdown，供 Dify Chatflow 的知识库检索节点消费。

**架构位置**：采集脚本 → Markdown 快照 → Dify 知识库 L2 注入 → N2a 知识库检索 → N4b Execute 分析

---

## 二、已实现功能

### 2.1 Amazon BSR 榜单采集

- 导航到指定品类的 Best Sellers 页面
- 抓取 Top 10 产品的：ASIN、标题、评分、评论数、价格
- 根据 BSR 排名计算权重（#1→1.0, #10→0.1，线性递减）
- 支持飞行前校验：验证页面标题、面包屑导航、产品卡片数量
- 支持 BSR 节点自动发现（`discover_bsr_node` 方法，备用）

**关键发现**：宠物饮水机在 Amazon US 的实际 BSR 节点是 `2975263011`（Pet Supplies > Cat Fountains），而非预期的 Dogs > Automatic Fountains（`3117462011` 不存在）。该发现通过搜索+产品页反查确认。

### 2.2 产品页内嵌评论采集

- 从产品详情页的内嵌评论区域提取评论
- 每产品采集 6-10 条合格评论（Top Reviews）
- 输出字段：星级、日期、标题、正文、Verified Purchase 标识、weight
- 自动滚动触发懒加载
- 支持产品页内翻页尝试

**为什么不用独立评论页**：Amazon 在 2026 年收紧政策，非住宅 IP（数据中心/VPN）访问 `/product-reviews/` 路径被强制重定向到登录页。即使家宽代理配合登录 cookies，带 URL 参数（`?filterByStar=`、`?pageNumber=`）的请求也会触发 sign-in 重定向。产品页内嵌评论是目前唯一零依赖可用的方案。

### 2.3 筛选规则

| 条件 | 值 | 目的 |
|------|-----|------|
| 最低词数 | 50 词 | 过滤无意义短评 |
| Verified Purchase | 必须 | 确保真实购买 |
| 评论时效 | 18 个月内 | 保证数据新鲜度 |
| Weight 继承 | 产品 BSR 排名 → 每条评论 | LLM 分析时优先头部竞品 |

### 2.4 输出格式

```
# Amazon BSR 快照: Pet Water Fountain
> 采集时间 / 市场 / BSR节点

## BSR Top 10 产品
| BSR# | ASIN | 产品名称 | 评分 | 评论数 | 价格 | weight |

## 评论快照
### #1 ASIN — 产品名 | weight=1.0
> 好评 N | 差评 N
| # | 星级 | 日期 | 标题 | 评论内容 | Verified | weight |
```

### 2.5 反爬策略

- 随机延迟（2-5 秒）+ 产品间冷却（8 秒）
- 移除 `navigator.webdriver` 标识
- 真实 User-Agent 和 viewport
- 验证码检测 + 截图留存 + 中断
- 每产品采集后即时存 JSON（中断不丢数据）

## 三、难点与踩坑记录

### 3.1 BSR 节点 ID 验证（已解决）
**现象**：`3117462011` 加载后页面标题为 "Best undefined"  
**根因**：该 NodeID 在 Amazon US 站点不存在  
**解决**：通过搜索关键词 → 进入产品页 → 提取 BSR 节点链接 → 确认正确 ID 为 `2975263011`

### 3.2 BSR 页面选择器变化（已解决）
**现象**：`zg-grid-general-faceout` 选择器返回 0 个元素  
**根因**：Amazon 在 2026 年更新了 BSR 页面的 CSS 类名  
**解决**：通过 HTML dump 定位实际选择器：`div#gridItemRoot` → `div[data-asin]` → 各字段精确选择器

### 3.3 独立评论页全面封锁（已解决，通过产品页替代）
**现象**：`/product-reviews/ASIN/` 路径被强制重定向到 Sign-In  
**根因**：Amazon 2026 年政策收紧，非住宅 IP + 未登录用户无法访问独立评论页  
**测试过的方案**：

| 方案 | 结果 |
|------|------|
| 北美家宽代理 + 无 cookies | Sign-In |
| 北美家宽代理 + 登录 cookies | 基础 URL 可用，带参数即被重定向 |
| 北美家宽代理 + cookies + star filter | 触发额外认证检查，session 即焚 |
| 北美家宽代理 + cookies + pageNumber | 同上报废 |

**最终方案**：从产品详情页（`/dp/ASIN/`）采集内嵌评论，无需登录和 cookies。

### 3.4 评论选择器双格式（已解决）
**现象**：产品页和独立评论页使用不同的 data-hook 值  
**根因**：产品页用 `reviewTitle`/`reviewText`（驼峰），独立页用 `review-title`/`review-body`（连字符）  
**解决**：解析器同时兼容两种格式

### 3.5 1688 供应商采集（未实现）
**现象**：所有自动化方案均被滑块验证码拦截  
**测试过的方案**：
- Playwright + stealth 脚本 → 概率性通过但无产品数据（需登录）
- Playwright + 登录 cookies → 滑块验证码
- 真实 Chrome 可执行文件（executable_path）→ 滑块验证码
- Playwright persistent context（用户 Chrome profile）→ Chrome 限制主 profile 远程调试
- alibaba.com 国际站 → 同样被验证码拦截
- CDP（Chrome DevTools Protocol）连接 → 用户多次尝试端口连接被拒

**根因**：1688/Alibaba 反爬系统检测到了自动化控制，疑似检测了 CDP/DevTools 协议的痕迹  
**结论**：1688 采集暂不自动化，后续可考虑：
- 专业反反爬服务（Bright Data / ScrapingBee）
- 1688 移动端 APP API（通常反爬较弱）
- 手动采集后结构化导入

### 3.6 价格选择器修复（已解决）
**现象**：价格字段全部输出 "N/A"  
**根因**：Amazon 给类名加了 hash 前后缀（`_cDEzb_p13n-sc-price_3mJ9Z`），精确匹配 `span.p13n-sc-price` 失败  
**解决**：改用部分属性匹配 `span[class*='p13n-sc-price']`

### 3.7 Unicode 编码兼容（已解决）
**现象**：Windows GBK 终端环境下 `print("✓")` 报 `UnicodeEncodeError`  
**解决**：所有特殊字符替换为 ASCII，运行时设置 `PYTHONIOENCODING=utf-8`

## 五、运行方式

```bash
# 安装依赖（首次）
pip install playwright greenlet
python -m playwright install chromium

# 运行采集
cd N7爬取脚本
PYTHONIOENCODING=utf-8 python amazon_bsr_scraper.py

# 输出
output/Pet_Water_Fountain_<timestamp>.md   # 结构化快照（上传 Dify 知识库）
output/Pet_Water_Fountain_<timestamp>.json # 原始数据备份
output/bsr_page.png                        # BSR 页面截图（验证用）
```

**品类配置**：修改脚本顶部 `CONFIG` 字典的 `category`、`search_keyword`、`bsr_url`、`bsr_node_id` 四个字段即可切换品类。

**网络要求**：当前 Amazon 采集**不需要**代理或 VPN（产品页和 BSR 页均可在非美国 IP 访问）。但如果后续要接入独立评论页翻页，需要美国住宅代理 + 登录 cookies。
